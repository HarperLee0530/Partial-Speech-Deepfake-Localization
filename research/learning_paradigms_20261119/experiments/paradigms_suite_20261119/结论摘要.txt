课件其他学习范式小型筛选：结论摘要
2026-11-19

已经完成六个方向、两个随机种子的试验，包含30个模型状态、60组条件评价、13类预定配对比较。
六个方向是迁移学习、多任务学习、协同训练、域适应、持续学习、元学习；域适应是迁移学习的子类。
总体判断：最清楚的正向信号是WavLM对通道变化的稳健性，以及更新模型时使用旧样本回放。
本轮没有证据支持把多任务边界损失、双模型伪标签或一阶MAML直接加入正式主模型。

1. 迁移学习：低通条件下有效，但并非所有指标都提升
比较：冻结通用WavLM + 投影 + 原CNN，对照Log-Mel + 原CNN；两者使用相同384条标注录音和对应训练预算。
WavLM有额外预训练数据与编码器/投影参数，因此这是系统方案比较，不是参数量匹配的单因素消融。
两个种子平均结果：
  原音频事件F1：49.22% -> 54.01%。但两种子的变化分别为+11.14、-1.55个百分点，原域提升不稳定。
  原音频帧F1：83.55% -> 78.12%；EER：12.24% -> 15.00%，存在明确取舍。
  低通音频事件F1：29.46% -> 54.53%。两种子分别提升27.25、22.88个百分点。
  低通真实时长误报率：54.31% -> 7.71%；短事件召回：11.56% -> 51.60%。
结论：支持继续使用/研究已有WavLM迁移路线，尤其关注通道稳健性；不能声称全面优于CNN，也不是为项目增加了一个此前没有的方法。

2. 多任务学习：这套边界辅助监督配方没有收益
原音频事件F1：49.22% -> 48.91%；低通：29.46% -> 28.99%。
这是在相同20轮教师之后，加4轮边界辅助监督的实验，并未搜索更多损失强度或从第一轮联合训练。
结论：本轮不支持增加该辅助损失；不能否定整个多任务学习范式。

3. 协同训练：高精度伪标签仍未带来稳定定位收益
Mel学生原音频事件F1：49.22% -> 49.50%；低通：29.46% -> 29.62%，变化很小。
WavLM学生原音频事件F1：54.01% -> 53.08%；低通：54.53% -> 53.19%。
共同筛选的伪标签覆盖率约38.88%和44.19%，选中时长上的准确率约98.38%和99.41%。
伪标签质量诊断在全部训练和阈值冻结后才读取对应真值，没有回灌训练。
结论：不能仅凭伪标签精度高就宣称定位会变好；本配方不建议并入主模型。
这是一轮双视图一致性筛选的协同训练启发方案，未证明经典协同训练的条件独立假设。

4. 域适应CORAL：新条件改善，原条件下降
使用768条低通未标注训练录音做特征协方差对齐，没有使用这些录音的真值。
低通事件F1：29.46% -> 35.46%，两个种子都改善。
原音频事件F1：49.22% -> 46.99%，两个种子都下降。
低通误报率从54.31%降至32.83%，仍然很高；低通EER仅从31.36%变为30.98%。
结论：体现了目标条件适应与原条件保持的取舍，不是无代价的泛化增强。

5. 持续学习：旧样本回放比直接微调更值得继续
这里先有源模型，再用384条低通训练录音的标签更新；所有变体沿用源模型阈值。
回放组把目标条件与旧clean数据损失各占一半，额外使用一次旧数据前向计算。
相对直接微调：
  原音频事件F1：45.89% -> 51.14%，两个种子分别+3.26、+7.23个百分点。
  原音频误报率：17.40% -> 7.06%。
  低通事件F1：38.98% -> 39.07%，基本持平，不支持明显的新域提升。
  低通误报率：16.26% -> 14.63%。
回放后原音频误报率仍高于更新前源模型的4.57%，不能说完全消除了旧条件退化。
EWC能部分降低误报，但事件F1没有显示稳定优于直接微调，本轮表现不如回放的证据清楚。
结论：新增训练方案优先考虑新旧条件混合训练/旧样本回放。本结果来自小型CNN实验，尚未在当前正式WavLM主方案上验证。

6. 元学习：没有验证出稳定的少样本适应优势
使用另一对相同WavLM小型MLP头，普通ERM与一阶MAML各200个episode；三个合成通道任务。
两者再用相同32条独立band支持录音做相同5步更新。适应后沿用适应前阈值。
适应后低通事件F1：ERM 19.40%，一阶MAML 19.62%；两个种子差值分别+0.82、-0.39个百分点。
一阶MAML自身的低通事件F1平均从适应前20.20%降到19.62%。
结论：这套小型配方没有证明“学会更快适应”；当前不值得增加元学习复杂度。
这里只是三个合成通道任务上的一阶近似可行性试验，不是标准多任务基准，也不是二阶MAML的完整评估。

建议
保留现有WavLM迁移方向。若继续做新增实验，优先检查适应新通道时的新旧样本混合训练/回放，而不是继续堆辅助模块。
CORAL可作为有明确目标通道的适应候选，但必须约束原域退化；本轮不直接采用。
所有结论都应经过更大训练规模、更多种子和真实未见域验证后，再决定是否修改正式方案。

重要边界
本次标注训练384条、隐藏标签训练768条；256条开发校准、另384条留出评价。
本次两组开发UID与上一轮小实验的开发UID互斥，但官方开发集在历史项目中用过，不是全新独立测试集。
“低通”是3.4kHz六阶Butterworth因果滤波，未补偿群延迟；它只是合成通道变化，不能证明新伪造算法泛化。
CORAL、持续学习和元学习拥有不同的目标条件数据/标签权限，不能把所有方案排成同一公平排行榜。
两个随机种子、多项探索性比较；配对bootstrap没有多重比较校正，也不涵盖训练波动或同源依赖。
正式eval与LPS未用于本次实验；原有模型权重未改动，没有自动替换主模型。
模型hash、阈值来源、数据/缓存一致性、梯度检查、逐录音指标重汇总均通过。
