目的：检验预训练 WavLM 特征加接入层是否改善现有部分伪造定位系统。
mel_control：原 CPU LogMel80 缓存 -> 原 CNN-BiGRU -> 完整 boundary 组合。
wavlm_frozen：冻结 WavLM-Base-Plus 最后一层768维 -> LayerNorm768 -> Linear768到80
              -> 相同 CNN-BiGRU -> 相同 boundary 组合。
接入层额外增加63056个参数。WavLM维度没有频率轴含义，80维是学习到的坐标，
不能宣称这与Mel频带是相同表示，或把结果当作参数量完全匹配的纯特征消融。
WavLM冻结94381936个参数，使用额外94000小时预训练音频，不是只用PS从零学习。
来源 https://huggingface.co/microsoft/wavlm-base-plus

官方预处理 do_normalize=false，输入16kHz单声道，不自行加全录音标准化。

帧对齐：WavLM卷积总步长320样本、感受野400样本。左右各补40样本，
中心为159.5+320*t样本；原录音先按官方160ms标签存储长度补尾。
逐录音完整前向，不跨录音注意力，不人为把短录音串接，不裁掉尾帧；
训练与评价仅按实际时长权重计算，有效20ms细标签沿用原官方标签。
WavLM全程eval/no_grad，禁用训练时dropout及SpecAugment；冻结后可缓存float32特征。
同一录音的原声/20dB白噪声/轻微EQ都来自现有确定性增强，train3视图、dev/eval仅原声。
WavLM有整段上下文，后端还有双向GRU；这是离线系统。

训练：双方CNN随机初始化相同；投影层初始化隔离随机数状态，避免改变公共CNN/dropout序列。
train6345/dev2484，seed666，20轮，batch8，AdamW lr.001/wd.0001，梯度裁剪5。
保留双分辨率、局部交叉注意力、分歧门控、可学习粗聚合、边界辅助和片段内部一致性。
五项损失系数1/1/.5/.1/.05，不另外调学习率、隐藏层或WavLM输出层。
全部新增可训练层和CNN端到端训练，WavLM权重始终冻结。
每轮dev真实时长FPR<=5%，按dev事件F1选轮次，epoch0可选，平局保留早轮。
两组完成、冻结权重和阈值之后才提取eval特征和计算测试指标。
