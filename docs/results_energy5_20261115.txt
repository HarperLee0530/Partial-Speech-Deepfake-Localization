PS 主方案加入5维能量的配对实验结果（2026-11-15，seed666）

结论：本轮不支持加入现有主方案。保留原boundary；energy5作为负收益消融存档。
两组各20轮均已完成，42份逐轮开发集归档、固定阈值测试和独立审计均通过。

比较对象
control：CNN-BiGRU＋信道增强＋双分辨率＋局部注意力＋分歧门控＋边界辅助组合。
energy5：只在上述细分支GELU前增加零初始化5→32无bias能量投影（160个参数），其余结构和损失相同。
两组从相同随机CNN和adapter初始化，全参数训练；不是把旧冻结CNN的小修正头直接叠加。
train6345/dev2484/eval3562；20轮、batch8、每组15880次更新；AdamW lr=.001、wd=.0001、clip=5。
原声/20dB噪声/轻微EQ确定性轮换，数据顺序和五项损失一致。
控制组937014个有效训练参数；能量组937174个。

选模与阈值
每轮先在开发集按真实时长误报率≤5%校准，再按开发集事件F1选择；epoch0可选，平局保留早轮。
两组都选epoch19。control开发集事件F1=78.991094%，真实时长FPR=4.999638%，logit阈值=0.42304700613021856。
energy5开发集事件F1=78.217822%，真实时长FPR=4.999758%，logit阈值=-0.0468684434890747。
两组冻结后才使用测试集，测试集不选模型、不调阈值。开发集≤5%不保证测试集也≤5%。
评价协议ps_native20_event_v2：实际20ms标签、连续正帧合并，无平滑/补空隙/最短过滤；IoU≥0.5一对一匹配。

同时Frame F1与时长F1上升，说明逐帧/时长改善并不等于事件定位改善。这里只陈述结果，不据此认定能量破坏了边界。
按本项目预先固定的事件F1主指标及误报指标，当前证据支持保留原boundary。

实现与复核
5维能量只使用train clean有效帧拟合均值/标准差；同一实际增强波形提取，尾部按真实时长mask。
纯5维与旧14维对应列逐值一致；train/dev全部21519视图的LogMel与前端缓存逐值一致。
独立审计重新计算42份dev指标和阈值、两组test指标及逐录音匹配；缓存绑定、归一化和权重哈希通过。
control第0–20轮dev logits与历史boundary归档逐值一致，最终测试汇总也复现历史主方案数值。
本工作树69项单元测试通过（8.877s）。最终CPU单音频CLI两组均通过：同一dev录音的阈值、判决及事件与GPU归档一致。
CPU与GPU分数最大绝对差control=2.2888e-05、energy5=3.0518e-05；本轮报告以归档分数为准，不宣称跨设备分数逐值相同。

单条16kHz单声道音频推理（在code目录，输出文件必须不存在）
python -m cnn_ps.predict_energy --audio example.wav --output prediction_energy.json --device cpu
python -m cnn_ps.predict_energy --audio example.wav --output prediction_control.json --checkpoint ../weights/boundary_control_energytrial_seed666.pt --device cpu
predict_energy默认加载energy5实验权重；checkpoint自带完整CNN、adapter、训练统计和dev阈值，不需训练缓存或标签。
原predict_main仍用于现有主方案；predict_energy的默认候选不表示推荐替换主方案。

结论边界：只有seed666，eval此前已分析；这是本轮条件下的负收益对照，不能推广为所有模型/数据都不应使用能量。
