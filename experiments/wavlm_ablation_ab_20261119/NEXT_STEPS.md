# A/B组综合结论与下一步方案（仅计划，未开始训练）

## 模块取舍

| 模块或设计 | 当前建议 | 当前事件F1证据 |
|---|---|---|
| 第6/9/12层可学习融合 | 保留 | 优于仅第12层8.42pp、仅第6层1.53pp、固定平均2.89pp |
| 下游局部跨分辨率注意力 | 保留 | 关闭后降低1.47pp |
| 下游可学习粗细门控 | 保留 | 改固定0.5后降低1.47pp |
| 边界辅助监督 | 保留 | 关闭后降低1.57pp |
| 同段一致性损失 | 保留 | 关闭后降低1.53pp |
| WavLM卷积位置嵌入 | 保留 | 关闭后降低3.07pp |
| WavLM相对位置偏置 | 保留 | 关闭后降低4.59pp |
| 可学习粗聚合/下采样 | 优先验证固定平均池化替代 | A5提高1.31pp；95%区间[+0.53,+2.14]pp，但FPR增加0.59pp |
| 粗分支辅助损失 | 可考虑简化，先验证 | 关闭提高0.50pp，95%区间[-0.28,+1.28]pp，证据不足 |
| WavLM内部位置门控 | 非优先简化候选 | 固定1后降低0.39pp；完整模型优势区间[-0.49,+1.30]pp，尚不能证明等效 |

注意两种门控不是同一个模块：A7是定位后端粗细融合门控，B2是WavLM内部相对位置偏置门控。B2尚无明确F1贡献证据，不等于A7可以删除。

“保留”是当前配置下的保守工程决定，不是证明普遍有效。没有针对投影层、CNN-BiGRU、整条粗分支或全部辅助模块联合移除的实验，不能从本轮结果推断它们可以删除。A10只关闭粗分支的额外监督，粗分支及最终160ms主损失仍然存在。

更高短事件召回未必是改善：例如B3短事件召回增加约2.11pp，但事件精确率从70.90%降至63.46%，事件F1明显下降。需联合观察精确率、召回和误报。

## 优先级1：复核A5，确定实际可接受的误报取舍

比较完整A0与固定平均池化A5。保持其他配置不变，各补seed667、668，共4次新训练；已有seed666结果仅在环境、源码与条件核验后复用。每个seed使用配对公共初始化和样本顺序。报告三个seed的均值、标准差和逐seed差值，避免只挑最好一次。

主要目标为事件F1，重点同时报告真实时长FPR和短事件召回。当前A5相较A0：F1 +1.3077pp，短事件召回+3.2753pp，FPR +0.5883pp，EER -0.3671pp。因此先将A5视为候选，A0继续作为固定参照。使用dev比较相同误报约束下的表现；部署所需误报容忍应预先确定，不能根据测试结果倒推一个刚好通过的标准。

固定池化只少2048个后端参数，约占原后端0.2%，收益主要是结构简化与本轮定位表现；不能据一次32条录音计时声称明显加速。单独第6层在当前实现中仍执行完整12层WavLM，也不自动获得编码器推理加速。

## 优先级2：针对误报做训练集难负样本加权

在优先级1选定的候选上，比较原训练与“只对训练集中高分真实帧适度增权”。不改变采样、模型结构及其他损失，先限制权重上限，避免以大幅降低召回换取低误报。先在train/dev重新诊断难例位置，再预先确定一小组权重；不能用eval错误反向构造训练样本。

这项针对A5暴露的F1/误报取舍；期待提高事件Precision并控制真实时长FPR，提升幅度未知。若无稳定增益，保留原设置。

## 优先级3：只调整粗分支辅助损失权重

在前两步固定的结构上比较coarse_aux=0.5、0.25、0，其余主20ms、主160ms、boundary、consistency权重保持原样。每次只改变这一项，用dev选择并配对多seed复核。

没有验证过“固定池化+关闭粗辅助”组合，不能把A5和A10的单独收益相加。若组合需要测试，至少保留完整/A5/A10/A5+A10的2×2对照，才可区分交互；新增组合按新实验记录，不改写历史消融表。

## 暂不优先

不删除WavLM相对偏置或卷积位置嵌入，不先关闭下游注意力、门控、边界或一致性。B2固定位置门控的性能接近并不证明等效，且目前没有可靠速度优势证据，优先级低于池化与误报优化。

若误报得到控制后仍以短事件为主要瓶颈，再单独尝试有上限的短事件监督增权；不要同时调整全部损失或加入多种新模块。

## 评价约束

继续保留train/dev用于训练和选择；历史eval只能作为已查看的探索性基准。最终泛化结论应在未参与本轮选择的新保留集/外部数据上检验。此前已查看过的LPS也不能重新称为盲测。

现有95%bootstrap区间条件于固定训练模型、未做多重比较校正，不能覆盖重训不确定性，也不代表说话人聚类区间。多个消融的条件贡献不能相加。本方案没有承诺任何提升幅度，所有新训练和组合实验都尚未启动。
