# SAL前端替换实验：原WavLM与普通Log-Mel

实验于 **2026年11月17日22:25（北京时间）完成**。本目录供组员撰写报告和复核结果：将SAL中的WavLM前端替换为我们原CNN方案的普通Log-Mel，保留SAL后端、损失与训练规则，与已经完成的缩减数据WavLM-SAL实验比较。

**结论：在沿用原SAL训练配方的条件下，移除WavLM后，PS测试EER从4.50%上升到23.14%，伪造帧F1下降25.49个百分点、事件F1下降42.07个百分点。这支持WavLM前端对这套系统有重要作用，但不能将性能贡献按百分比分摊给WavLM和SAL技巧。**

> **评价口径：以下PS指标全部使用160ms官方标签，LPS指标使用20ms标签。Log-Mel特征步长是20ms，不等于PS评价也是20ms。不能直接与我们主方案的原生20ms事件F1比较，更不能据此宣称普通特征主方案胜过SAL。** 本实验也不是WavLM-Base-Plus第6/9/12层融合实验；这里参照的是原WavLM-Large SAL系统。

## 1. 测试结果

PS eval：同一固定清单的 **3,562条录音**；两组预测UID、标签字节和录音时长逐条核对一致。

| 指标（%） | 原WavLM＋SAL | 普通Log-Mel＋SAL | 普通特征减WavLM（百分点） |
|---|---:|---:|---:|
| EER ↓ | 4.5031 | 23.1425 | +18.6394 |
| 伪造类帧F1 ↑ | 95.3837 | 69.8934 | −25.4902 |
| 真实类帧F1 ↑ | 95.6344 | 78.5517 | −17.0827 |
| 帧准确率 ↑ | 95.5125 | 74.9496 | −20.5629 |
| 事件F1（tIoU≥0.5）↑ | 89.2314 | 47.1572 | −42.0742 |

LPS crossfade：同一固定清单的 **3,800条录音**。

| 指标（%） | 原WavLM＋SAL | 普通Log-Mel＋SAL | 普通特征减WavLM（百分点） |
|---|---:|---:|---:|
| EER ↓ | 37.9094 | 52.2657 | +14.3564 |
| 伪造类帧F1 ↑ | 62.4415 | 74.8076 | +12.3661 |
| 真实类帧F1 ↑ | 57.6757 | 12.2271 | −45.4486 |

**LPS不能只看伪造类F1。** 普通特征版将357,549 / 389,937个真实帧误判为伪造，真实帧误报率约91.69%；原WavLM版为17.40%。普通特征版偏向预测伪造，伪造类F1升高同时伴随真实类F1、EER和事件定位恶化。两组跨数据集定位都较弱，不能说WavLM已经解决泛化。

| 数据集 | 伪造类帧F1差值95%区间（百分点） | 事件F1差值95%区间（百分点） |
|---|---:|---:|
| PS eval | [−26.3903, −24.5999] | [−43.2865, −40.8826] |
| LPS | [+10.5196, +14.2009] | [−6.0228, −4.6349] |

区间条件于这两个已选模型，只反映录音抽样波动，不包括训练随机性、选模不确定性或源录音聚类相关性；未计算EER置信区间。

## 2. 改动与保持项

普通特征版输入链为：

```text
16kHz单声道波形
→ 原cnn.LogMel：80维、n_fft=512、win_length=400、hop_length=320
→ 原方案的LayerNorm(80)
→ 新增必要的Linear(80,1024)输入维度适配
→ 原SAL两层1024维Conformer
→ 原平均池化（PS每8个20ms帧聚合；LPS测试不做8倍池化）
→ 原8类位置头＋2类真假头
```

Log-Mel提取代码直接复用原方案，包括补齐、功率谱、Mel参数和自然对数。移除WavLM及其层混合参数，不加载旧SAL任务权重；新任务参数随机初始化。普通特征版共23,791,786个可训练参数。

保持SPL位置监督、`aligned_cross_recording_v1`修正后的CSM两轮、mixup_ratio=0.2、位置损失＋10倍二分类损失、RawBoost算法4及0.5概率。与旧SAL运行对应的37个vendor Python文件核对一致（前端工厂扩展除外），详见[协议审计](protocol_audit.json)。本次没有重新训练WavLM参照组。

| 项目 | 设置 |
|---|---|
| 数据 | train_detector 5,076；dev 2,484；PS eval 3,562；LPS 3,800 |
| 随机种子 / batch | 888 / 8 |
| 优化器 | Adam，lr=1e-5，weight_decay=1e-4 |
| 学习率调度 | StepLR，每10轮乘0.1 |
| 训练规则 | 至少40、最多60轮，开发集EER早停patience=10 |
| 实际轮数 | 两组均40轮；普通特征选第23轮，原SAL选第25轮 |
| 最佳开发EER | 普通特征12.8548%；原SAL1.8525% |
| 精度 | FP32，确定性训练；CPU累计验证EER |
| 选模及测试 | 仅开发EER选权重；测试使用固定二分类argmax，不用测试EER阈值调F1 |

## 3. 指标定义及报告结论边界

- 标签`0=伪造、1=真实`；帧分类用两个logit的argmax，平分选0。
- EER使用连续`logit_real−logit_fake`及原SAL最近FPR/FNR交点公式。EER阈值仅用于该统计量，不用于F1或事件解码。
- 事件由连续伪造标签/预测构成，末端裁到音频时长；tIoU≥0.5最大匹配数优先的一对一匹配，再按总IoU处理平局。PS的160ms标签边界不代表20ms真实声学边界。
- 这是**固定配方的前端替换实验**。移除WavLM同时移除了大型预训练表示和对应结构，并加入必要的输入映射；不能称为单独隔离“预训练”这一因素。
- 原1e-5学习率及快速衰减可能更适合预训练前端，未对Log-Mel组进行独立开发集超参数优化；不能宣称Log-Mel＋SAL已达最优。
- 缺少同设置的“Log-Mel＋去掉SPL/CSM”消融，无法由此判断SAL后续技巧没用，或量化每个技巧的独立收益。
- 训练在11月17日15:27电脑重启时中断。19:52从第7轮末完整检查点恢复模型、优化器、调度器和回调状态，从第8轮续训。旧检查点未保存随机数状态，续训重新设seed888，不等价于逐位复现不中断运行。
- 只有一个训练种子；旧测试集已有历史查看，LPS亦有历史探索，不称为新的盲测。原始运行路径仅用于溯源。

**可直接用于报告的表述：**

> 在固定缩减数据划分及原SAL训练配方下，我们以原方案的80维Log-Mel替换WavLM前端，并保留SAL后端、位置辅助监督和交叉片段混合。PS测试集上，EER由4.50%上升至23.14%，伪造类帧F1由95.38%降至69.89%，事件F1由89.23%降至47.16%。该结果支持WavLM前端对本配置的识别与定位性能具有重要作用，但尚不足以分离预训练、模型容量、优化配方及SAL各技巧的独立贡献。上述PS指标按160ms标签评价。

在本目录执行`python verify_results.py`即可复核，不需要音频、GPU或模型权重。训练环境沿用原SAL Python3.10 / torch2.2.1+cu121 / torchaudio2.2.1 / lightning2.0.8等，详见预测元数据及vendor依赖。
