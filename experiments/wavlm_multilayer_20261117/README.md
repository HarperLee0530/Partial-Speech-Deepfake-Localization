# 冻结WavLM多层融合：独立发布包（2026-11-17）

本目录保存已完成的第12层基线与第6/9/12层融合对照实验。所有内容均为新增文件，仓库原有的 `code/`、`docs/`、`weights/` 和默认入口保持不变。

## 实测结果

同机、同随机种子666、相同数据与初始化，两组各训练20轮；按开发集真实时长FPR≤5%校准阈值，再按开发集事件F1选择模型。完整测试集有3,562条录音。

| 测试指标 | 本次第12层基线 | 三层融合 | 变化（百分点） |
|---|---:|---:|---:|
| 事件F1，IoU≥0.5 ↑ | 65.2588% | **73.6767%** | **+8.4179** |
| ≤320ms短事件召回 ↑ | 66.7273% | **72.6020%** | +5.8747 |
| 真实时长误报率 ↓ | 6.8283% | **5.7043%** | −1.1239 |
| 20ms帧F1 ↑ | 84.4350% | **90.0013%** | +5.5662 |
| 帧EER ↓ | 12.3540% | **8.4517%** | −3.9023 |

按录音配对的2,000次bootstrap中，事件F1增益的95%区间为 **[+7.3685, +9.4339]个百分点**。这只描述当前两个固定模型的录音采样不确定性，不包含重新训练的随机种子波动。

## 改动范围

WavLM-base-plus全部94,381,936个参数冻结；同一次前向取得Transformer第6、9、12层输出。`hidden_states[0]` 是Transformer输入，因此不算第1层。

```text
w = softmax([a6, a9, a12])
h = w6*h6 + w9*h9 + w12*h12
h -> 原有LayerNorm768 -> Linear80 -> CNN/GRU -> 原有双分辨率模块
```

仅增加3个可学习标量，初始权重均为1/3。最佳融合模型选自第18轮，权重约为 **0.704303 / 0.149284 / 0.146412**；冻结阈值为 **−0.17905920743942258**。输出是原始假音频logit，不是概率。

没有改变原有后端结构、损失、数据增强、学习率、batch size、随机种子或选模规则。`code/cnn_ps/` 保存实际实验时的完整模块快照；与检查点绑定的源码字节和哈希保持一致。发布时只给外层运行脚本增加了可移植路径参数，没有更改训练算法。

## 数据泄露与结论边界

- 本次正式对照的梯度更新仅使用train；dev用于阈值和轮次选择。第6/9/12层组合在完整训练前固定，没有使用本次完整eval结果搜索层组合或重新调阈值。
- 正式全量eval的特征提取与模型评价在两组训练结束、权重和阈值冻结后进行。标签格式转换与文件清单准备不参与训练或选模。
- 项目历史上已查看过eval；本次独立冒烟检查也使用过2条eval录音验证流程，没有用其分数选择模型。**因此不能把这里的eval称为从未接触过的最终盲测集。** 持续依据同一eval的表现迭代方案，存在测试集适应和结果偏乐观的风险。
- 已有清单检查的是跨split的UID互斥；未做全库音频内容去重、来源录音/说话人级重叠审计，也未审计公开WavLM预训练语料与本任务数据的重叠，不能据此宣称绝对不存在任何泄露。
- 本实验是单随机种子的整体融合消融；不单独证明每一层，或学习权重相对固定平均，各自独立有效。

本发布包保留上述限制，结论是“在现有划分和固定评价流程下观察到改善”，不是对完全独立新数据上的性能保证。
